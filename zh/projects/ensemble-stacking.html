深度学习 · 集成方法

最弱的模型，组成了最好的集成

四个 CNN——LeNet、AlexNet、VGG 和 ResNet-18——在 CIFAR-10 上训练，再用一个可学习的 meta-network stack 起来。 任何一个模型与自身的多个副本做 stacking，都能提升 2–3 个百分点；不同模型之间 stacking 提升更多，而表现最好的三元组合 竟然包含 LeNet——它单独的准确率只有 68%，而 AlexNet 是 86%。报告解释了为什么这一点很难提前规划； 这个页面则把它直接演示出来。

Stacking，实时运行

四个 inductive bias 各不相同的 base learner，加上一个在它们输出上拟合的 logistic regression meta-learner——即 Wolpert 的 stacked generalisation（堆叠泛化）， 在三个互不相交的数据划分上规范地完成。

测试集上的两两分歧率

两个学习器预测出不同类别的频率。这就是直接测量出来的多样性，也正是决定 stacking 是否有效的量。 报告转而去求助偏差和方差——而这两者无法从一个训练好的 CNN 中读出——于是它的组合搜索只能盲目进行。

参与 stacking 的 base learner

先从三个 weak learner 开始：没有一个能画出这条曲线，但各自出错的区域不同，stacking 后的结果胜过其中最好的一个。 现在加入 k-NN。它单独就足够强，以至于 stacking 结果几乎变成了 k-NN 本身——其他学习器几乎没有什么可以纠正的了。 stacking 买单的是多样性，而不是强度。

实验设置

CIFAR-10 包含 60,000 张 32×32 的彩色图像，十个类别，数量均衡。训练集用 random_split 划分为训练集和验证集；data augmentation 采用水平翻转、colour jitter 和旋转——并且刻意不用垂直翻转，因为那会让一辆汽车 跑到"汽车"这一分布之外。

四个 base learner，选择标准是彼此不同，而不是各自最强。LeNet 从头训练；AlexNet 和 VGG 从 ImageNet 预训练权重 fine-tune，冻结卷积部分、只训练分类器；ResNet-18 同样 fine-tune。每个模型在两种学习率下共训练六次， 报告中给出的是最佳一次的测试准确率。

meta-learner 本身也是一个小型神经网络。它的输入是各 base learner 类别概率的拼接，输出是最终的十分类预测。 它用 Adam、学习率 1e-3，在 base learner 的输出上训练十个 epoch。

Stacking 带来了什么

同一模型的多个副本

第一组对照：把同一架构独立训练出的三个或六个副本 stack 起来。这能单独分离出 meta-learner 仅靠平均训练噪声 所能获得的收益。

全线提升 2 到 3 个百分点——而六个副本比三个几乎没有多出什么。同一架构独立训练出的副本之间确实 存在一点分歧，但不多，到第三个副本时 meta-learner 已经把能榨取的都榨取完了。

值得记住的结果。三个单独最强的模型放在一起得到 88.51。把 ResNet 换成 LeNet——用一个 68% 的模型替换一个 84% 的模型——集成的准确率反而上升到 88.67。LeNet 并不是更好的分类器， 而是一个更不同的分类器：它从头训练而非从 ImageNet fine-tune，浅而非深，因此犯的错误是另外两个 模型不会犯的。而这正是 meta-learner 唯一能利用的东西。

这个差距很小，而且来自单次训练，所以不应过度解读为排名。它真正确立的是方向：把失败模式不同的模型 组合起来，胜过把失败模式相同的模型组合起来，即便要以单个模型的准确率为代价。

哪些没有奏效

报告对此相当坦诚，而这一点值得重申，因为页面顶部的演示正是对它的直接回应。

stacking 本应在成员之间平衡偏差与方差。但这两个量都无法从一个训练好的 CNN 中读出。没有它们，就没有 原则性的方法来决定该 stack 哪些模型——所以上面的组合实验是一次搜索，而不是一次设计。它的 结果是真实的；只是没有任何事先测得的量能解释它们。

实用的替代指标——报告没有用，而演示用了——是两两分歧率：在留出集上，两个模型预测出不同类别的频率 有多高？计算成本低，而且直接回答了 stacking 需要知道的问题。在挑选组合之前先对四个 CNN 算出这个矩阵， 是显而易见的下一步；它很可能无需搜索就会指向 LeNet + AlexNet + VGG。

报告指出的另一个缺口，是候选池中没有 Transformer——ViT 本可以带来一种真正不同的 inductive bias，按照上面 的论证，那正是这个集成所需要的。Model soups（对权重而非输出取平均）被列为另一个方向：获得类似集成的 收益，却不必付出类似集成的推理成本。
