图像取证 · 信号处理 · 无需训练

相机在每个像素里都留下了指纹，generative model 却没有。

几乎所有相机传感器都透过 Bayer CFA 在每个像素只看到一种颜色，另外两种靠插值补出。 这一步插值会在成片中留下一种微弱而规则的结构。而一张来自 Stable Diffusion 或 Midjourney 的图像从未经过传感器，因此不存在这种结构。我们仅凭这一事实构建了一个检测器：把图像按四种可能的 Bayer 布局分别 re-mosaic（重新马赛克化），再做一次 demosaic（去马赛克），然后测量四个结果之间的分歧有多大。 相机照片会产生分歧，生成图像则不会。在 46,000 张生成图像上，这一离散度以 97–100% 的准确率区分了真假—— 同一个测试也恰好说明了：一旦照片经过 JPEG 压缩或缩放，方法为何立刻失效。

核心思路

AI 生成图像的检测器通常是分类器：在真实图像和生成图像上训练一个网络，指望它学到能够迁移的东西。 多数时候它学不到——在某个生成器的输出上训练的模型，往往在下一个生成器上失效，因为它学到的只是 那个生成器的癖好。我们想要的是一个依赖于相机特性、而非生成器特性的测试，这样它才能适用于 一个谁都还没见过的生成器。

这个特性就是 CFA（colour filter array，滤色阵列）。单传感器相机无法在同一个感光点上同时测量红、绿、蓝， 所以它在传感器上铺一层滤色片马赛克——绝大多数是 Bayer 图案，每一个红和蓝对应两个绿——然后在每个像素 用邻域插值重建缺失的两种颜色。这一步就是 demosaicing（去马赛克），它是每一张成片的源头。 插值出的值与其邻域之间的相关性，取决于传感器用的是四种 Bayer 布局中的哪一种：RGGB、BGGR、GRBG 或 GBRG。

于是测试是这样的：假装这张图像是传感器的原始读数。按照图案 P 在每个像素丢掉三种颜色中的两种， 用与相机同类的算法把它们插值回来，再把结果与原图比较。如果图像确实来自布局为 P 的传感器， 这次插值会在很大程度上复现相机当年做的事，差异很小；在其余三种错误布局下差异则更大。如果图像从未 经过传感器，四种布局同样地“错”，四个差异几乎完全相同。我们最终保留的统计量是四个 PSNR（峰值信噪比）值的 标准差：照片的值大，生成图像的值接近零。

在得到结果之前，我们先在数字里发现了什么

测试最直白的版本——选出得分最高的图案，看它是否以明显优势胜出——是我们最先尝试的，结果令人失望： 最佳图案与相机真实布局吻合的比例只有约 58%。逐张查看图像解释了原因。RGGB 与 BGGR 的分数总是彼此接近， GRBG 与 GBRG 也是如此；真正的大差距出现在两组之间。组内谁胜出几乎是抛硬币，但组间差距却很稳健。 对全部四个值取标准差，就能在无需猜对赢家的情况下捕捉到这个差距，而这正是奏效的版本。

四万七千张图像，一条轴

来自项目结果文件的、每张图像在四种图案间的 PSNR 离散度——999 张来自 RAISE 的相机 RAW、1,000 张来自 DiffusionDB 的 Stable Diffusion 图像、44,000 张来自 GenImage 八个生成器的图像，以及团队自己生成的 1,000 张照片级写实风景图。实心直方图是按原样测试的图像；轮廓线是同一批 RAISE 照片经 JPEG 压缩或 缩放之后的结果。采用对数轴，因为两个群体相距三十倍。

在 (0, 100)——接受真实图像完整范围内的一切——时，RAISE 中几十张几乎没有离散度的离群点把下阈值拖到 0.026 dB，让大多数伪造图像蒙混过关。从两端各裁掉 1%，DiffusionDB 的检出率就从 35% 升到 100%， GenImage 从 25% 升到 96%，代价是 2% 的真实照片。这一权衡就是论文的表 I；其中 PSNR 一列在这里 由逐张原始结果重新计算，精确到每一位数字。

数字说明了什么

分离是真实的，而且很大。相机照片的离散度中位数为 1.01 dB；DiffusionDB、GenImage 和团队自己生成的风景图分别为 0.032、0.043 和 0.024 dB。以真实集合的第 5 和第 95 百分位为阈值， DiffusionDB 的 100%、风景图的 100% 和 GenImage 的 97.3% 被标记为伪造，同时 90% 的真实照片被保留—— 这是构造使然。GenImage 是最诚实的数字：八个生成器，包括 GAN 和 Midjourney，没有任何一个被用来调参。 在尝试过的指标中 PSNR 最有效；SSIM 和 CIEDE2000 色差紧随其后，而团队同样计算过的视频指标 VMAF 则无法区分两个集合（DiffusionDB 检出率 0%）。

re-demosaic 所用的算法比预想的更重要。我们不知道某台相机具体用了什么专有插值， 所以团队用 Malvar–He–Cutler 之外的三种替代算法重复了实验。普通 bilinear 插值和 OpenCV 的边缘感知方法 仍能分开两个集合，但差距小得多——真实集合的中位数为 0.22 和 0.16 dB，DiffusionDB 为 0.016。 可变梯度数（variable number of gradients）demosaicing 对两者都给出 0.009 dB，只检出 3% 的伪造图像： 它对每种布局的处理几乎完全相同，因此没有离散度可测。Malvar 滤波器是线性且与图案绑定的， 这正是错误图案会“吃亏”的原因。

希望读者权衡的两点。第一，这里的“真实”指的是来自三台 Nikon 机身的单一数据集， 由数据集方以从 RAW 显影得到的 TIFF 提供；1 dB 的离散度是否能推广到其他厂商的处理流程并未经过测试， 结题汇报中也如实说明。第二，阈值是同一真实集合的百分位，所以“真实保留率”一列是设计选择，而非测量结果。 真正测得的量是每种选择下的伪造检出率，而提供证据的是伪造集合——来自三个数据集、八个不同生成器的 46,000 张图像。

开发方法

流程最初是一个 MATLAB 原型——rgb2cfa、MATLAB 自带的 demosaic， 在一张 RAISE 图像上算 PSNR 和 SSIM——用来确认这个想法能否产生任何信号；随后为了规模化用 Python 重建。Malvar–He–Cutler 插值是四个 5×5 线性滤波器（其中一个转置使用）；团队把开源的 colour-demosaicing 实现改造成带反射填充的批量 PyTorch 卷积，使一张图像的四种图案、 以及大量图像可以在 GPU 上同时运行，并调到与 MATLAB 输出一致。PSNR、SSIM 和 CIEDE2000 以同样方式 从 scikit-image 移植；VMAF 通过 FFmpeg 运行。结果按图像逐张写成 JSON——每个指标的四个分数、 最佳图案、离散度——分析 notebook、百分位阈值以及六个训练好的分类器（logistic regression、SVM、random forest、 k-NN、AdaBoost、GMM）都从这些文件读取。一个直接在“真实 vs 伪造”上训练的 ResNet-50 作为传统基线。

本页面的 JavaScript 从零重新实现了 re-mosaic、Malvar 滤波器和 PSNR；发布前我按项目的约定 （镜像填充、四舍五入取整）做了核对，它能逐像素复现 Python 的输出。本页面的直方图和每一个阈值下的 准确率都是由随附的结果文件重新计算的，而非从论文中抄录。
