Historical time-travel simulator

An interactive simulation where the player is dropped into a historical moment and explores / acts within it, built on the same LLM + real-time image/sound engine as the Turtle Soup game.

Status: Parked. This is an outline, not an implementation — recorded so the idea and its open questions aren't lost. It will change as I think it through. Created 2026-09-12 · last updated 2026-09-12.

Core idea (in my words)

  • Basic concept aligns with Turtle Soup: LLM-driven interaction, real-time generated scenes and sound, each session unique.
  • Recorded now so it isn't lost; work starts only after the Turtle Soup engine exists.

What carries over from Turtle Soup

  • Scene Director + scene bible (visual consistency across a session).
  • Image and sound-effect generation on state change.
  • Structured game state driving the LLM rather than free-form chat.

What is new (to think through later)

  • Grounding: the "hidden truth" becomes real history — need a fact source (curated notes, retrieval over reference material) so the simulation doesn't hallucinate events.
  • Interaction model: exploration / dialogue with historical figures / "what would you do" decisions, instead of yes/no questions.
  • Scope control: pick one narrow moment (a single day, a single city) per scenario rather than open-world.
  • Educational vs. entertainment framing — decides how strict the historical grounding must be.

Open questions (do not resolve yet)

  • Which historical moments first?
  • Free-form roleplay vs. goal-based scenario (e.g. "survive the day", "solve the mystery")?
  • Language: Chinese-history scenarios in Chinese, or English-first?
