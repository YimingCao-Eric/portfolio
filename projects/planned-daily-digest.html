Personalized daily news digest

A daily digest that scrapes topics I care about from free sources — GitHub Trending, latest products from major AI companies, new software releases — summarizes them, and delivers one readable page each morning.

Core idea (in my words)

  • Sources are free and public: GitHub Trending, AI company announcements, software release feeds.
  • Personalized to my interests; summarized so I read one digest instead of a dozen sites.

Proposed outline

Sources (initial list)

  • GitHub Trending (daily / weekly, by language of interest — Python, TypeScript, etc.).
  • AI companies: official blogs / changelogs / release notes (Anthropic, OpenAI, Google DeepMind, Meta AI, Mistral, etc.) via RSS where available.
  • Software releases: GitHub Releases feeds for tools I use; Hacker News front page as a catch-all.
  • Optional later: arXiv categories, Product Hunt, selected newsletters.

Pipeline

  1. Fetch — RSS/Atom first, HTML scraping only where no feed exists; respect rate limits and robots.
  2. Dedupe + filter — drop items seen before; score relevance against an "interest profile" (a short text describing what I care about, editable by me).
  3. Summarize — per item: one-line what-it-is, why-it-matters-to-me, link. Group by section.
  4. Compose — a single Markdown/HTML page; "top 5 today" at the top, the rest below.
  5. Deliver — email, a local file, a Telegram/Discord message, or a static page. Scheduled daily (cron / scheduled task).

Personalization ideas

  • Interest profile in plain text + thumbs up/down on items to tune the ranking over time.
  • Track "things I opened" to learn what I actually read.
  • Weekly roll-up in addition to daily.

Key questions

  • How much LLM summarization is worth paying for vs. just titles + relevance ranking? (Start cheap: rank first, summarize only the top N.)
  • Where do I want to read it — email vs. chat app vs. browser tab?
  • Should this share ingestion with the news fact/opinion project (idea 04)? Probably yes for the fetch/dedupe layer.

Milestones

  1. Script that pulls GitHub Trending + 3 RSS feeds and prints a Markdown digest.
  2. Add dedupe store (SQLite) and interest-profile ranking.
  3. Add LLM summaries for the top items; schedule daily.
  4. Delivery channel of choice; feedback buttons.

Tech notes

  • Python, feedparser/httpx, SQLite, a small LLM call for summaries; cron or a hosted scheduled task.
  • Reuse JHA scraping/dedupe patterns.
